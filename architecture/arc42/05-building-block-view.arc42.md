# 5. Building Block View

<!-- arc42:section 05 -->

The top-level building blocks are the bounded contexts listed in
`../domain/bounded-contexts.yml`:

- Architecture Authority;
- Agentic Delivery Control Plane;
- Agentic Primitives;
- Developer Distribution;
- Public Organization Governance; and
- Private Copilot Publication.

The Structurizr DSL is the authoritative C4 model source. This chapter
references that model rather than duplicating its relationships.
